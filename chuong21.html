Dung Sai Kích Thước (Tolerancing)

Dung sai trực tiếp, cộng trừ, giới hạn, dung sai góc, lắp ghép tiêu chuẩn Metric/Inch.

1. Khái niệm dung sai

Trong gia công cơ khí, không thể chế tạo chi tiết chính xác tuyệt đối. Dung sai (Tolerance) xác định phạm vi sai lệch cho phép của kích thước so với kích thước danh nghĩa.

Thuật ngữTiếng AnhGiải thích
Kích thước danh nghĩaNominal SizeKích thước thiết kế (ví dụ: 50mm)
Sai lệch trênUpper DeviationGiá trị lớn nhất chấp nhận (+0.05)
Sai lệch dướiLower DeviationGiá trị nhỏ nhất chấp nhận (-0.05)
Dung saiToleranceHiệu = Sai lệch trên - Sai lệch dưới
Kích thước giới hạn lớnMaximum Limit50.00 + 0.05 = 50.05
Kích thước giới hạn nhỏMinimum Limit50.00 - 0.05 = 49.95

2. Các cách ghi dung sai

a. Dung sai cộng trừ (Plus/Minus)

Có 2 dạng: đối xứng (±) và không đối xứng (sai lệch trên ≠ dưới):

Đối xứng: 50 ± 0.05 Không đối xứng: 50 +0.05 / -0.02 // Kích thước từ 49.98 đến 50.05

b. Dung sai giới hạn (Limit Tolerances)

Ghi trực tiếp kích thước lớn nhất và nhỏ nhất:

Ghi dạng giới hạn: 50.05 / 49.95 // Số lớn ghi phía trên, số nhỏ ghi phía dưới

3. Ghi dung sai trong AutoCAD

Tạo dung sai qua Dimension Style Manager

Command: D ↵ (mở Dimension Style Manager) → Chọn style → Modify → Tab "Tolerances" Method: Chọn kiểu dung sai: • Symmetrical: Đối xứng (±) • Deviation: Không đối xứng (+/−) • Limits: Giới hạn (Max/Min) • Basic: Kích thước cơ bản (đóng khung) Upper value: 0.05 (sai lệch trên) Lower value: 0.02 (sai lệch dưới) Precision: 0.00 (2 chữ số thập phân)

Ghi dung sai nhanh bằng Text Override

Trong Mtext editor: Gõ: 50 {\H0.7x;\S+0.05^-0.02;} // \H0.7x: chiều cao ký hiệu = 70% text chính // \S: stacked text (xếp chồng trên/dưới)

4. Dung sai góc (Angular Tolerances)

Áp dụng tương tự cho kích thước góc:

Ví dụ: 45° ± 0.5° // Trong Dim Style, tab Tolerances, // chọn Method = Symmetrical, Value = 0.5

5. Lắp ghép tiêu chuẩn (Standard Fits)

Hệ thống lắp ghép xác định mối quan hệ kích thước giữa lỗ và trục:

Loại lắp ghépTiếng AnhĐặc điểmỨng dụng
Lắp lỏngClearance FitTrục luôn < Lỗ → có khe hởBạc đạn, trục quay tự do
Lắp trung gianTransition FitCó thể hở hoặc dôi nhẹVỏ ổ lăn, chốt định vị
Lắp chặtInterference FitTrục luôn > Lỗ → phải ép vàoBánh răng ép trục, vành ổ bi

6. Ký hiệu lắp ghép ISO

Hệ thống ISO dùng chữ cái + số để ký hiệu. Chữ IN HOA = Lỗ, chữ thường = Trục:

Ví dụ: Ø50 H7/g6 // H7 = Dung sai lỗ (H = zero deviation dưới) // g6 = Dung sai trục (g = clearance fit) // Kết quả: Lắp lỏng có khe hở nhỏ
Ký hiệu lỗKý hiệu trụcLoại lắp
H7f6, g6, h6Lắp lỏng
H7js6, k6, m6Lắp trung gian
H7p6, r6, s6Lắp chặt
