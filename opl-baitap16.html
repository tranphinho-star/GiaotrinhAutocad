📖 ONE POINT LESSON ⚙️ Mức Độ 16

Tính Toán & Vẽ Bánh Răng + Biểu Đồ Cam

Hướng dẫn chi tiết từng bước trong AutoCAD: Công thức tính toán → Vẽ vòng tròn bánh răng → Cặp ăn khớp → Biểu đồ chuyển vị cam.

📋 Tổng quan kiến thức

📐
Công thức cốt lõi bánh răng thẳng (Spur Gear)
Tất cả tính toán dựa trên 2 thông số đầu vào: Module (m) và Số răng (Z). Từ đó tính ra toàn bộ kích thước vòng tròn.
Đại lượngKý hiệuCông thứcÝ nghĩa
Đường kính chiaDD = m × ZVòng tròn 2 bánh răng tiếp xúc nhau
Đường kính đỉnhDaDa = m × (Z + 2)Vòng ngoài cùng (đỉnh răng)
Đường kính chânDfDf = m × (Z − 2.5)Vòng chân răng (đáy rãnh)
Bước răngpp = π × mKhoảng cách giữa 2 răng liền kề
Chiều cao rănghh = 2.25 × mTừ đỉnh đến chân răng
Khoảng cách trụcaa = m(Z₁+Z₂)/2Khoảng cách giữa 2 tâm bánh răng ăn khớp

⚙️ BT16.1 — Tính toán bánh răng thẳng

Cho: m = 2.5, Z = 24 → Tính D, Da, Df, p, h → Vẽ 3 vòng tròn

Bước 1: Tính toán các thông số

Dữ kiện: Module m = 2.5  |  Số răng Z = 24
Thông sốCông thứcThay sốKết quả
Đường kính chia (D)m × Z2.5 × 24D = 60 mm
Đường kính đỉnh (Da)m × (Z + 2)2.5 × 26Da = 65 mm
Đường kính chân (Df)m × (Z − 2.5)2.5 × 21.5Df = 53.75 mm
Bước răng (p)π × m3.14159 × 2.5p = 7.854 mm
Chiều cao răng (h)2.25 × m2.25 × 2.5h = 5.625 mm

Bước 2: Thiết lập Layer

1 Tạo 3 Layer cho 3 loại nét vẽ
Command: LA ↵ (mở Layer Properties Manager)

── Tạo các layer:
Layer "Pitch" → Màu Orange (30) → Linetype: CENTER (nét chấm gạch)
Layer "Addendum" → Màu Green (3) → Linetype: Continuous (nét liền đậm)
Layer "Dedendum" → Màu Red (1) → Linetype: Continuous (nét liền mảnh)
💡Nếu chưa có Linetype CENTER: gõ LINETYPE → Load → Chọn file acad.lin → Chọn CENTER.

Bước 3: Vẽ vòng chia (Pitch Circle)

2 Vẽ vòng tròn chia D = 60mm
── Chuyển sang Layer "Pitch"
Command: C ↵ (CIRCLE)
Specify center point: 0,0 ↵
Specify radius or [Diameter]: D ↵
Specify diameter: 60 ↵
💡Có thể nhập bán kính 30 thay vì chọn Diameter.

Bước 4: Vẽ vòng đỉnh (Addendum Circle)

3 Vẽ vòng tròn đỉnh Da = 65mm
── Chuyển sang Layer "Addendum"
Command: C ↵
Specify center point: 0,0 ↵
Specify radius or [Diameter]: D ↵
Specify diameter: 65 ↵

Bước 5: Vẽ vòng chân (Dedendum Circle)

4 Vẽ vòng tròn chân Df = 53.75mm
── Chuyển sang Layer "Dedendum"
Command: C ↵
Specify center point: 0,0 ↵
Specify radius or [Diameter]: D ↵
Specify diameter: 53.75 ↵

Kết quả BT16.1

✓ 3 vòng tròn đồng tâm hoàn chỉnh

Kết quả: 3 vòng tròn đồng tâm tại gốc (0,0) với màu sắc và kiểu nét phân biệt.

Bước 6 (Nâng cao): Ghi kích thước

5 Ghi chú kích thước bằng DIM
Command: DIMDIA ↵ (Diameter Dimension)
Select arc or circle: (click vòng đỉnh)
Dimension text = 65 → kéo ra ngoài

── Lặp lại cho vòng chia (D=60) và vòng chân (Df=53.75)

🔗 BT16.2 — Cặp bánh răng ăn khớp

Cho: Z₁ = 20, Z₂ = 40, m = 3 → Tính khoảng cách trục a → Vẽ 2 vòng chia tiếp xúc

Bước 1: Tính toán thông số 2 bánh răng

Thông sốBánh 1 (Z₁=20)Bánh 2 (Z₂=40)
Đường kính chia DD₁ = 3×20 = 60mmD₂ = 3×40 = 120mm
Đường kính đỉnh DaDa₁ = 3×22 = 66mmDa₂ = 3×42 = 126mm
Đường kính chân DfDf₁ = 3×17.5 = 52.5mmDf₂ = 3×37.5 = 112.5mm
Khoảng cách trục: a = m × (Z₁ + Z₂) / 2 = 3 × (20 + 40) / 2 = 90 mm

Bước 2: Thiết lập vị trí tâm

1 Xác định 2 tâm cách nhau 90mm
── Tâm bánh 1 tại gốc, tâm bánh 2 sang phải 90mm
Command: POINT ↵
Specify a point: 0,0 ↵ (Tâm O₁)

Command: POINT ↵
Specify a point: 90,0 ↵ (Tâm O₂)

── Vẽ đường trục nối 2 tâm (Layer Center)
Command: L ↵
From point: -10,0 ↵
To point: 100,0 ↵ → ↵

Bước 3: Vẽ 3 vòng tròn — Bánh 1 (tại O₁)

2 Vẽ bánh răng nhỏ Z₁ = 20
── Layer "Addendum" (Nét liền xanh lá)
Command: C ↵ → Center: 0,0 → Diameter: 66 ↵

── Layer "Pitch" (Nét chấm gạch cam)
Command: C ↵ → Center: 0,0 → Diameter: 60 ↵

── Layer "Dedendum" (Nét liền đỏ)
Command: C ↵ → Center: 0,0 → Diameter: 52.5 ↵

Bước 4: Vẽ 3 vòng tròn — Bánh 2 (tại O₂)

3 Vẽ bánh răng lớn Z₂ = 40
── Layer "Addendum"
Command: C ↵ → Center: 90,0 → Diameter: 126 ↵

── Layer "Pitch"
Command: C ↵ → Center: 90,0 → Diameter: 120 ↵

── Layer "Dedendum"
Command: C ↵ → Center: 90,0 → Diameter: 112.5 ↵

Kết quả BT16.2

✓ Cặp bánh răng ăn khớp hoàn chỉnh

2 vòng chia tiếp xúc nhau tại điểm ăn khớp. Khoảng cách trục a = 90mm.

💡
Kiểm tra nhanh
Sau khi vẽ xong, dùng lệnh DIST đo khoảng cách 2 tâm → kết quả phải = 90mm. Dùng LIST kiểm tra bán kính từng vòng tròn.

📈 BT16.3 — Biểu đồ chuyển vị cam

Rise 30mm (0°-120° Harmonic) → Dwell (120°-180°) → Return (180°-300° Uniform) → Dwell (300°-360°)

Phân tích 4 pha chuyển động

🔼 Rise (Nâng)

0° → 120°

Harmonic Motion
h: 0 → 30mm
Đường cong Sin

⏸ Dwell (Dừng)

120° → 180°

Đứng yên
h = 30mm
Đường ngang

🔽 Return (Hạ)

180° → 300°

Uniform Motion
h: 30 → 0mm
Đường thẳng xiên

⏸ Dwell (Dừng)

300° → 360°

Đứng yên
h = 0mm
Đường ngang

Bước 1: Vẽ hệ trục tọa độ

1 Tạo trục X (góc) và trục Y (hành trình)
── Quy ước: 1° cam = 1mm trên bản vẽ (360° = 360mm dài)
── Trục Y: 30mm = 30mm thực

Command: L ↵ (LINE — Trục X)
From point: 0,0 ↵
To point: 360,0 ↵ → ↵

Command: L ↵ (LINE — Trục Y)
From point: 0,0 ↵
To point: 0,35 ↵ → ↵ (cao hơn 30 một chút)

Bước 2: Đánh dấu các mốc góc

2 Chia trục X tại 120°, 180°, 300°, 360°
── Vẽ đường dọc tại các mốc pha
Command: L ↵ → From: 120,0 → To: 120,35 ↵ → ↵
Command: L ↵ → From: 180,0 → To: 180,35 ↵ → ↵
Command: L ↵ → From: 300,0 → To: 300,35 ↵ → ↵
Command: L ↵ → From: 360,0 → To: 360,35 ↵ → ↵

── Vẽ đường ngang mốc h=30mm
Command: L ↵ → From: 0,30 → To: 360,30 ↵ → ↵

Bước 3: Vẽ pha Rise — Harmonic (0°→120°)

3 Vẽ đường cong Harmonic Motion
Công thức Harmonic: h = (H/2) × [1 − cos(π × θ/β)]
Với H = 30mm, β = 120°. Tính h tại mỗi 15°:

── Vẽ LINE qua từng điểm:
Command: L ↵
From: 0,0 ↵
To: 15,1.14 ↵
To: 30,4.39 ↵
To: 45,9.26 ↵
To: 60,15 ↵

💡Hoặc dùng SPLINE thay LINE cho đường cong mượt hơn. Vẽ xong có thể dùng PEDIT → Fit để làm mượt polyline.

Bước 4: Vẽ pha Dwell (120°→180°)

4 Đường ngang tại h = 30mm
Command: L ↵
From: 120,30 ↵
To: 180,30 ↵ → ↵

Bước 5: Vẽ pha Return — Uniform (180°→300°)

5 Đường thẳng xiên từ (180,30) → (300,0)
── Uniform motion = vận tốc đều = đường thẳng
Command: L ↵
From: 180,30 ↵
To: 300,0 ↵ → ↵

Bước 6: Vẽ pha Dwell cuối (300°→360°)

6 Đường ngang tại h = 0mm
Command: L ↵
From: 300,0 ↵
To: 360,0 ↵ → ↵

Kết quả BT16.3

✓ Biểu đồ chuyển vị cam hoàn chỉnh

Bước 7 (Nâng cao): Ghi chú và hoàn thiện

7 Thêm text annotation và tiêu đề
── Ghi tên các pha bằng MTEXT
Command: MT ↵
First corner: 30,34 ↵ → 110,38 ↵
Text: RISE (Harmonic) ↵

── Lặp lại cho: DWELL, RETURN (Uniform), DWELL

── Ghi mốc góc trên trục X bằng TEXT
Command: DT ↵ → Tại (0,-3): 0°
Command: DT ↵ → Tại (120,-3): 120°
Command: DT ↵ → Tại (180,-3): 180°
Command: DT ↵ → Tại (300,-3): 300°
Command: DT ↵ → Tại (360,-3): 360°

Tổng kết OPL — Mức độ 16
BT16.1: Tính D=60, Da=65, Df=53.75, p=7.854, h=5.625. Vẽ 3 vòng tròn đồng tâm bằng CIRCLE.
BT16.2: Tính a=90mm. Vẽ 6 vòng tròn (3 cho mỗi bánh), 2 vòng chia tiếp xúc.
