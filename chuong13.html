Tạo Khối (Block)

Gộp nhiều đối tượng thành một khối duy nhất để tái sử dụng nhiều lần (như Bàn, Ghế, Cửa...).

1. Định nghĩa Block là gì?

Khối (Block) là một tập hợp các đối tượng được nhóm lại thành một đối tượng duy nhất (VD: vẽ 1 cái bồn cầu gồm hinh ovan, hcn, elip... sau đó gom lại thành 1 cục đặt tên là "BonCau").

  • Ưu điểm: Giảm dung lượng bản vẽ, dễ quản lý.
  • Cập nhật đồng loạt: Khi sửa 1 block gốc, tất cả các block copy từ nó trong bản vẽ sẽ tự động cập nhật theo (ví dụ đổi cánh cửa 800 thành 900 trên toàn bộ mặt bằng).

2. Lệnh tạo khối cục bộ BLOCK (B)

BLOCK / MAKE BLOCKB
Menu BarNhập lệnh
Draw → Block → Make...Block hoặc B

Hộp thoại Block Definition hiện ra. Ta cần khai báo 3 yếu tố quan trọng nhất:

  1. Name: Đặt tên cho Block (VD: CuaSo, GheSofa...).
  2. Base point (Pick point): Chọn điểm mốc chèn Block. Đây là tay cầm để di chuyển cực kỳ quan trọng (Thường nằm ở tâm, gốc hay bản lề cửa).
  3. Objects (Select objects): Quét chọn tất cả các đối tượng sẽ biến thành Block.

Sau khi chọn xong, nhấn OK.

💡
Thuộc tính Object khi tạo Block
Retain: Giữ nguyên đối tượng gốc.
Convert to block: Biến đối tượng gốc thành Block (Khuyên dùng).
Delete: Xóa luôn đối tượng gốc.

3. Lệnh tạo khối toàn cục WBLOCK (W)

WBLOCK / WRITE BLOCKW

Block tạo bằng lệnh B chỉ dùng được trong Tệp bản vẽ hiện tại. Lệnh W cho phép xuất Block thành một file .DWG riêng biệt để dùng cho mọi bản vẽ khác (Xây dựng thư viện CAD cá nhân).

Command: W ↵ Trong hộp thoại Write Block: - Chọn Source là Objects (hoặc chọn thẳng tên Block đã có sẵn). - Chọn Base point và Select objects như phần trên. - Chọn đường dẫn để lưu thành Tệp DWG ở mục File name and path.

4. Lệnh chèn khối INSERT (I)

INSERTI
Menu BarNhập lệnh
Insert → Block...Insert hoặc I

Dùng để lấy một Block đã có sẵn đưa ra màn hình làm việc.

  • Bảng Name: Chọn tên Block đã tạo bằng lệnh B.
  • Nút Browse...: Tìm file Block tải bên ngoài về, được tạo bằng lệnh W.
  • Đánh dấu vào phần Specify On-screen để có thể dùng chuột chọn vị trí đặt, góc xoay và phóng to thu nhỏ.

5. Phá vỡ đối tượng EXPLODE (X)

EXPLODEX

Khi muốn chỉnh sửa bên trong một cục Block, ta dùng lệnh X để phá rã Block đó thành các đoạn line, circle rạc rời như ban đầu.

Command: X ↵ Select objects: Chọn Block rồi Enter.
ℹ️
Block Editor
Trong CAD 2007 trở đi, ta có thể nhấp đúp chuột trái vào cục Block để mở môi trường Block Editor (BEDIT), sửa xong đóng lại và Save, toàn bộ Block cùng tên sẽ tự động được sửa theo (Không cần phá X ra rồi B lại nữa).
