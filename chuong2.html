Các Lệnh Về File

Quản lý file bản vẽ: tạo mới, lưu, mở, đóng và thoát khỏi AutoCAD.

1. Tạo File bản vẽ mới - Lệnh NEW

NEW Ctrl + N
Menu BarNhập lệnhToolbar
File → New...New hoặc Ctrl + N📄 (New)

Xuất hiện hộp thoại Select Template. Chọn biểu tượng acad, sau đó nhấn OK hoặc Enter.

2. Lưu File bản vẽ - Lệnh SAVE

SAVE Ctrl + S
Menu BarNhập lệnhToolbar
File → Save...Save hoặc Ctrl + S💾 (Save)

Trường hợp bản vẽ chưa được ghi thành file:

  1. Xuất hiện hộp thoại Save Drawing As
  2. Chọn thư mục, ổ đĩa ở mục Save In
  3. Đặt tên file vào ô File Name
  4. Chọn ô Files of type để chọn ghi file với phiên bản AutoCAD trước (nếu cần)
  5. Nhấn nút SAVE hoặc Enter

Trường hợp bản vẽ đã được ghi:

Chỉ cần nhấp chuột vào biểu tượng Save trên thanh công cụ hoặc Ctrl + S, AutoCAD sẽ tự động cập nhật.

⚠️
Lưu ý
Nếu thoát khỏi AutoCAD mà chưa ghi bản vẽ, sẽ xuất hiện hộp thoại hỏi có ghi bản vẽ không. Chọn YES để lưu.

3. Mở bản vẽ có sẵn - Lệnh OPEN

OPEN Ctrl + O
Menu BarNhập lệnhToolbar
File → Open...Open hoặc Ctrl + O📂 (Open)
  1. Xuất hiện hộp thoại Select File
  2. Chọn thư mục và ổ đĩa chứa file cần mở: Look in
  3. Chọn kiểu file cần mở: File of type
  4. Chọn file cần mở trong khung
  5. Nhấn nút OPEN hoặc Enter

4. Đóng bản vẽ - Lệnh CLOSE

CLOSE
Menu BarNhập lệnh
File → CloseClose

Nếu bản vẽ có sửa đổi, xuất hiện hộp thoại nhắc nhở:

  • YES: Ghi thay đổi trước khi đóng
  • NO: Không ghi thay đổi
  • Cancel: Huỷ bỏ lệnh Close

5. Thoát khỏi AutoCAD - Lệnh EXIT

EXIT / QUIT Ctrl + Q
Menu BarNhập lệnhPhím tắt
File → ExitExit, QuitCtrl + Q hoặc Alt + F4

Hoặc nhấn nút dấu X ở góc trên bên phải cửa sổ. Nếu chưa lưu sẽ có hộp thoại nhắc nhở tương tự lệnh Close.
