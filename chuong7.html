Các Lệnh Hiệu Chỉnh Tạo Hình

19 lệnh tạo hình mạnh mẽ: Offset, Trim, Extend, Chamfer, Fillet, và các lệnh tạo vùng Region.

1. Lệnh tạo đối tượng song song OFFSET (O)

OFFSETO
Command: O ↵ Specify offset distance: 50 Khoảng cách offset Select object to offset: Chọn đối tượng Specify point on side to offset: Chọn phía cần offset

2. Lệnh cắt đối tượng TRIM (TR)

TRIMTR
Command: TR ↵ Select cutting edges: Chọn cạnh cắt (Enter = chọn tất cả) Select object to trim: Chọn phần cần cắt bỏ
💡
Mẹo Trim nhanh
Nhấn Enter ngay khi chọn cutting edges → AutoCAD sẽ lấy tất cả đối tượng làm cạnh cắt (rất tiện dụng!).

3. Lệnh cắt mở rộng EXTRIM

Cắt tất cả đối tượng giao với đối tượng chọn về một phía. Nhanh hơn Trim khi cắt nhiều đối tượng cùng lúc.

4. Lệnh xén một phần BREAK (BR)

BREAKBR
Command: BR ↵ Select object: Chọn đối tượng (điểm chọn = điểm 1) Specify second break point or [First point]: Chọn điểm thứ 2 → xén phần giữa

5. Lệnh kéo dài đối tượng EXTEND (EX)

EXTENDEX
Command: EX ↵ Select boundary edges: Chọn cạnh chặn Select object to extend: Chọn đối tượng cần kéo dài

6. Lệnh thay đổi chiều dài LENGTHEN (LEN)

LENGTHENLEN

Thay đổi chiều dài đối tượng bằng cách nhập giá trị tuyệt đối, tăng thêm, phần trăm hoặc kéo động.

7. Lệnh vát mép CHAMFER (CHA)

CHAMFERCHA
Command: CHA ↵ [Polyline/Distance/Angle/Trim/Method]: D ↵ Specify first chamfer distance: 10 Khoảng cách vát 1 Specify second chamfer distance: 10 Khoảng cách vát 2 Select first line: Chọn cạnh 1 Select second line: Chọn cạnh 2

8. Lệnh bo góc FILLET (F)

FILLETF
Command: F ↵ [Polyline/Radius/Trim/Multiple]: R ↵ Specify fillet radius: 15 Bán kính bo góc Select first object: Chọn đối tượng 1 Select second object: Chọn đối tượng 2
💡
Nối góc vuông nhanh
Đặt bán kính Fillet = 0 → hai đường thẳng sẽ được nối lại tại giao điểm (rất hữu ích!).

9. Lệnh hiệu chỉnh đa tuyến PEDIT

PEDITPE

Hiệu chỉnh Polyline: nối các đối tượng thành Polyline, thay đổi bề rộng, thêm/xóa đỉnh, làm trơn...

10-11. Lệnh vẽ đường thẳng XLINE và RAY

LệnhViết tắtChức năng
XLINEXLVẽ đường thẳng vô tận (qua 2 điểm, cả 2 hướng)
RAY—Vẽ nửa đường thẳng (1 hướng từ điểm gốc)

12-14. Lệnh vẽ hình đặc biệt

20. Chamfer — Phương pháp vát theo góc (Angle)

Command: CHA ↵ [Polyline/Distance/Angle/Trim/Method]: A ↵ Chamfer length on first line: 15 Cạnh vát dài 15 Chamfer angle from first line: 30 Góc 30° so với cạnh 1
ℹ️
Chamfer/Fillet toàn bộ Polyline
Dùng option Polyline (P) trong CHAMFER hoặc FILLET → chọn Polyline → vát/bo tất cả các góc cùng lúc. Rất nhanh cho hình chữ nhật hoặc đa giác!

21. PEDIT Join — Nối nhiều đối tượng thành Polyline

Command: PE ↵ Select polyline [Multiple]: M ↵ Select objects: Quét chọn tất cả Line/Arc cần nối Convert Lines to polylines? [Yes/No]: Y ↵ [Close/Open/Join/Width...]: J ↵ Fuzz distance: 0.01 Sai số cho phép khi nối
